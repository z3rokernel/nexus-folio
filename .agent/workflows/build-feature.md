# /build-feature <name> — Build one feature from the specs

1. Find the feature in `docs/04-PAGES-COMPONENTS.md` and `docs/03-ANIMATION-SPEC.md`. Quote the acceptance criteria.
2. Write a mini-plan (files to create/modify).
3. Implement backend (route → controller → model → view), then the frontend module.
4. Add reduced-motion + mobile fallbacks.
5. Run the app; capture desktop (1440) + mobile (390) screenshots (and a short recording for animations).
6. Check the Definition of Done in `AGENTS.md`. Fix issues.
7. Commit with a Conventional Commit and tick the box in `docs/07-ROADMAP-CHECKLIST.md`.
